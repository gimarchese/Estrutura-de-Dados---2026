# Estrutura de Dados - 2026

Exercícios de estruturas de dados em C++ desenvolvidos na disciplina
de Estrutura de Dados do curso de Ciência da Computação (FMPFM).

## Conteúdo
Os materiais 0 a 4 reúnem exercícios sobre vetores, matrizes, pilha,
fila e algoritmos de ordenação. Há também um arquivo com a lista dos
materiais.
